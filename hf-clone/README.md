# Pet Paradise 🐾

An Animal Crossing-inspired virtual pet simulation game.

- Adopt and raise virtual pets
- Explore 6 habitats to encounter wild animals
- Emotional negotiation-based wild encounters
- Interactive mini-games and bond events
- 24 companion traits across 6 categories

Built with Java 21, Jakarta EE 11, Tomcat 10.1, and MySQL.
